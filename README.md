# Квест «Гарри Поттер» — Экспериментарий (Flask)

Мобильный сайт бронирования + Flask + PostgreSQL (Neon) + Telegram + админ-панель + экспорт Excel.

## Что уже реализовано

- Mobile-first вёрстка: сначала смартфоны, затем планшеты и компьютеры.
- Визуальная тема волшебной школы: винный, тёмный, золотой и пергаментный оттенки.
- Фотографии музея взяты с официального сайта `experimentariy.ru` (не сгенерированы): `des7.jpg`, `des5.jpg`, `des3.jpeg`.
- Форма заявки: имя, телефон, дата, время.
- Серверная проверка полей и понятное сообщение об успехе/ошибке.
- Сохранение заявок в PostgreSQL через `DATABASE_URL`; локально можно использовать SQLite.
- Telegram-уведомления (необязательно).
- Закрытая админ-панель `/admin`, статусы, комментарии, экспорт `.xlsx`.
- `/health` для проверки приложения и подключения к БД.

- Квест по мотивам Гарри Поттера.

## Быстрый локальный запуск на Windows

1. Установите Python 3.11 или новее.
2. Распакуйте ZIP в отдельную папку.
3. Откройте эту папку в Проводнике, в адресной строке напишите `cmd` и нажмите Enter.
4. Создайте виртуальное окружение:

   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   ```

5. Установите зависимости:

   ```bat
   pip install -r requirements.txt
   ```

6. Скопируйте `.env.example` в `.env`.
7. В `.env` обязательно задайте `FLASK_SECRET_KEY` и `ADMIN_PASSWORD_HASH`. Для локального запуска можно оставить `DATABASE_URL` пустым — тогда используется SQLite.
8. Запустите:

   ```bat
   python app.py
   ```

9. Откройте `http://127.0.0.1:5000`. Админ-панель: `http://127.0.0.1:5000/login`.

### Как сгенерировать секреты для `.env`

В командной строке (с активированным `.venv`) выполните:

```bat
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Скопируйте результат в `FLASK_SECRET_KEY`.

Затем выполните, заменив `ВАШ_НАДЁЖНЫЙ_ПАРОЛЬ` на свой пароль:

```bat
python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('ВАШ_НАДЁЖНЫЙ_ПАРОЛЬ'))"
```

Скопируйте полученный хеш в `ADMIN_PASSWORD_HASH`. Логин задаётся в `ADMIN_USERNAME`.

## Бесплатное размещение: Render + Neon

В этой схеме веб-приложение размещается на Render, а заявки хранятся отдельно в PostgreSQL Neon. Это важно: файловая система бесплатного веб-сервиса Render временная, поэтому SQLite-файл на Render не подходит для постоянных заявок.

### Часть A. Создать бесплатную базу Neon

1. Откройте [https://neon.com/](https://neon.com/) и зарегистрируйтесь.
2. Создайте новый проект PostgreSQL, например `experimentariy-quest`.
3. В панели проекта найдите **Connect** и выберите строку подключения (connection string). Если предлагается pooled connection, можно использовать её.
4. Скопируйте строку вида `postgresql://...`. Не отправляйте её в чаты и не публикуйте в репозитории — это пароль от базы.

На 30 октября 2026 года Neon Free заявляет бесплатную квоту, включая до 100 CU-hours на проект в месяц, 1 GB хранилища на проект и 5 GB исходящего трафика. База при бездействии засыпает после 5 минут; при исчерпании квоты вычисления могут быть приостановлены до следующего периода. Точные ограничения проверяйте в текущем кабинете Neon.

### Часть B. Загрузить проект на GitHub

1. Создайте аккаунт на [https://github.com/](https://github.com/).
2. Создайте новый **Private repository** (приватный репозиторий), например `experimentariy-quest`.
3. Загрузите содержимое этой папки в репозиторий. Не загружайте `.env`, базу данных, токены и пароли. Файл `.gitignore` уже исключает `.env` и локальную SQLite.

### Часть C. Развернуть Flask на Render

1. Откройте [https://render.com/](https://render.com/) и войдите через GitHub.
2. Нажмите **New → Web Service** и выберите приватный репозиторий `experimentariy-quest`.
3. Укажите:
   - Runtime: `Python 3`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
   - Instance Type: `Free` (если доступен в вашем аккаунте/регионе).
4. В разделе **Environment** добавьте переменные:
   - `FLASK_SECRET_KEY` — случайный длинный секрет, сгенерированный локально.
   - `ADMIN_USERNAME` — придуманный логин администратора.
   - `ADMIN_PASSWORD_HASH` — хеш пароля, сгенерированный командой выше.
   - `DATABASE_URL` — строка подключения Neon.
   - `COOKIE_SECURE` — `true`.
   - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — после создания Telegram-бота; пока можно не добавлять.
5. Нажмите **Create Web Service** и дождитесь статуса Live.
6. Откройте выданный Render URL. Проверьте `/health`: ответ должен содержать `"database":"postgresql"`.
7. Откройте `/login` и войдите в админ-панель.

### Часть D. Telegram (необязательно)

1. В Telegram найдите `@BotFather`, создайте бота командой `/newbot` и сохраните токен.
2. Напишите боту любое сообщение.
3. Получите chat ID через `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` (подставьте токен в адрес только у себя, не публикуйте его).
4. Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в Environment на Render и выполните Manual Deploy → Deploy latest commit.
5. Отправьте тестовую заявку. Заявка сохраняется в БД независимо от результата Telegram-уведомления.

## Важные ограничения бесплатного хостинга

- Бесплатный Render Web Service может засыпать после периода бездействия. Первый визит после сна может загружаться дольше.
- Файловая система бесплатного Render временная. Не используйте локальный SQLite для настоящих заявок — в этом проекте при наличии `DATABASE_URL` используется Neon PostgreSQL.
- Бесплатный Neon имеет лимиты вычислений, хранилища и трафика. При достижении лимита база может временно перестать принимать запросы, но данные в хранилище не должны удаляться из-за обычного сна compute. Делайте периодические выгрузки Excel и резервные копии.
- Бесплатные тарифы и их условия могут измениться. Перед запуском реального приёма заявок проверьте актуальные условия Render и Neon.
